# IELTS AI Speaking Classroom — Project State

**Last Updated**: 2026-08-07

## Executive Summary
The **IELTS AI Speaking Classroom** is a real-time web application designed for interactive IELTS speaking test practice. It features a Teacher Dashboard for creating rooms, managing live student turns, and viewing real-time evaluation summaries, as well as a Student interface for room entry, interactive voice recording, turn tracking, and personal scoring feedback generated by Google Gemini AI.

---

## Current Technical Stack

| Layer | Technology | Key Dependencies |
|-------|------------|------------------|
| **Frontend** | Next.js 15.5 (App Router, React 19) | `@supabase/ssr`, Tailwind CSS 4, Vitest, React Testing Library |
| **Backend** | FastAPI (Python 3.12) | Supabase Async Client, Google GenAI (`gemini-3.5-flash`), Uvicorn |
| **Database & Auth** | Supabase | PostgreSQL, GoTrue (JWT auth), Realtime subscriptions |
| **Storage** | Supabase Storage | `audio` bucket (WebM / MP4 recordings) with RLS policies |

## Active & Completed Features

### Completed Features
- ✅ **Authentication & Authorization**: SSR cookie-based session handling with `@supabase/ssr` on Next.js, and ES256 Bearer JWT token verification on FastAPI via Supabase `/auth/v1/user`. Role-based access control (`teacher` / `student`).
- ✅ **Automatic 401 Redirects**: Dedicated `useUnauthorizedRedirect` hook and standardized error handling across client components for session timeouts.
- ✅ **Teacher Room Management**: Room creation (Part 1, 2, 3 selection), room code generation, live turn starting/ending, participant roster monitoring.
- ✅ **Real-Time Turn State**: Supabase Realtime subscriptions (`postgres_changes` on `rooms` and `participants`) for instant turn updates without REST polling.
- ✅ **Student Recording & AI Scoring**: Browser audio recording, upload to Supabase Storage, transcript generation and 4-criteria IELTS scoring (Fluency, Grammar, Vocabulary, Pronunciation, Overall Band + action items) powered by `gemini-3.5-flash`.
- ✅ **Classroom Feedback Summaries**: AI-driven aggregate analysis summarizing common class weaknesses using Gemini.
- ✅ **Automated Testing Suite**: 39 Vitest frontend tests covering UI, hooks, and API layer; 12-step authorized backend end-to-end integration test flow (`scripts/test_flow.py`).
- ✅ **Writing Task 1 Practice**: Standalone (non-room) writing practice with 26 curated questions across all 7 Task 1 types, 78 model answers (Band 5 / 7 / 9 per question with criterion sub-scores, "why this band" explanations and improvement tips), a word-counter editor with draft autosave, and multi-teacher manual feedback on student submissions. Question diagrams are served from `frontend/public/writing-images/` (SVG/text fallbacks for chart types).
- ✅ **Writing Task 2 Practice**: Task 2 essays added on top of the same writing module via a `part` column (`1` = Task 1, `2` = Task 2). 24 curated essay questions across all 6 essay types (opinion, discussion, advantages & disadvantages, problem & solution, positive/negative development, two-part questions), 72 model answers (Band 5 / 7 / 9 per question), a 250-word target editor, and the same teacher review/feedback flow. Dedicated pages at `/student/writing/part2` and `/teacher/writing/part2`; navbar "Writing Task 2" links now active. Live DB has 50 questions (26 Task 1 + 24 Task 2) and 150 samples.
- ✅ **Writing Task 2 live seeding**: migration `20260807_writing_part2.sql` applied and `python -m scripts.seed_writing` run against the live project (non-destructive upsert; existing submissions/feedback preserved).
- ✅ **Self-service password reset**: `Forgot password?` link on the sign-in page → email link → `/reset-password` page (GoTrue recovery flow). Requires the `/reset-password` redirect URL to be added in Supabase Auth → URL Configuration.
- ✅ **Structural UX overhaul (Speaking / Writing modules)**: navbar now has separate **Speaking** and **Writing** dropdowns for students (Join a Session, My Speaking Report, Task 1/2 Practice, My Writing Submissions) and teachers (Speaking Rooms, Task 1/2 Review). New `/student/speaking` landing page; the student home page is now a hub with Speaking/Writing cards, a **My Badges** grid and a progress-report call-to-action.
- ✅ **Achievement badges**: 17 badges computed on-the-fly (no schema change) in `app/services/badges.py` — speaking (First Step, Talker 10, Chatterbox 25, Band 6/7/8 Speaker, Part 1/2/3 Explorer, Balanced Speaker) and writing (First Draft, Prolific Writer 10, Task 1 Explorer x7 types, Task 2 Explorer x6 types, Feedback Seeker, Band 7/8 Writer), each with earned state and progress. Exposed via `GET /api/me/badges`.
- ✅ **Public profiles**: `GET /api/users/{user_id}/profile` (authenticated) returns name, role, joined date, badges and aggregate stats only — never email/audio/transcripts. Public profile pages at `/profile/<user-id>` with a badge grid and stat summary.
- ✅ **Community leaderboards**: `GET /api/community` returns a **This Week** board (points reset every Monday so newcomers can rank), an **All Time** board, a 30-day **Improvers** board and a recent **Activity** feed. Frontend at `/community` with tabbed UI; student names link to profiles throughout (class scores, leaderboards, activity).
- ✅ **Automated tests**: 57 Vitest frontend tests (incl. new `badge-grid` and `community-tabs` suites); backend `scripts/test_community.py` (20-step integration flow covering badges, public profiles and community).

## Environment & Configuration

| Environment Variable | Service | Purpose |
|----------------------|---------|---------|
| `NEXT_PUBLIC_SUPABASE_URL` | Frontend | Supabase API endpoint |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Frontend | Supabase client anon key |
| `NEXT_PUBLIC_API_URL` | Frontend | Backend FastAPI service URL (default `http://localhost:8000`) |
| `SUPABASE_URL` | Backend | Supabase API endpoint |
| `SUPABASE_SERVICE_ROLE_KEY` | Backend | Supabase service key for administrative DB queries |
| `SUPABASE_ANON_KEY` | Backend | Supabase anon key for JWT verification |
| `GEMINI_API_KEY` | Backend | Google AI Studio API key |
| `GEMINI_EVAL_MODEL` | Backend | Evaluation & STT model identifier (`gemini-3.5-flash`) |
| `GROQ_API_KEY` | Backend | Optional: Groq Cloud API key (`whisper-large-v3-turbo` STT fallback) |
